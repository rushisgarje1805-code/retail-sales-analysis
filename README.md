## Project Overview

The **Retail Store Sales Analysis** project focuses on analyzing retail store sales data using **Power BI**.

The dataset was cleaned and prepared for analysis, relationships were created between the datasets, and DAX measures were formulated to generate useful insights. An interactive Power BI dashboard was then designed to present the analysis in a simple and understandable way.

---

## Objectives

* To analyze retail store sales data using Power BI.
* To clean and prepare the dataset for analysis.
* To create relationships between datasets.
* To formulate DAX measures.
* To identify important sales trends and patterns.
* To create an interactive and user-friendly dashboard.
* To present meaningful insights from the sales data.

---

## Tool Used

* **Power BI** – Data cleaning, data modeling, DAX measures, analysis, and dashboard visualization.

---

## Project Workflow

**Dataset Acquisition → Data Cleaning → Data Modeling → Relationships → DAX Measures → Dashboard Creation → Analysis**

---

## Power BI Dashboard

The dashboard provides an interactive view of the retail store sales data.

It helps analyze:

* Total Sales
* Sales Performance
* Product-wise Sales
* Category-wise Sales
* Sales Trends
* Overall Business Performance

Interactive filters, visuals, and charts make it easier to explore the data and understand the results.

---

## Conclusion

The **Retail Store Sales Analysis** project demonstrates the use of **Power BI** to transform retail sales data into meaningful visual insights.

The interactive dashboard helps users understand sales performance, identify trends and patterns, and analyze the overall performance of the retail store.
